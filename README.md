# ミナカ島戦記（マングース vs ハブ）

マングース軍とハブ軍が戦う、配置型の3Dオートバトラーです。Three.js で作り、PCとスマホのブラウザで動きます。

## 遊び方

```sh
npm install
npm run dev        # http://localhost:5173 （同じLANのスマホからも開けます）
```

1. タイトルで対戦形式（CPU戦／2人対戦）、陣営、マップ、CPUの強さを選びます。
2. 準備フェーズでは、予算50の範囲で、自陣の配置エリア（明るいマス）に兵と障害物を置きます。兵ごとに行動方針（前進／待機／防衛）を選べます。
3. 実戦フェーズは自動で進みます。プレイヤーは観戦するだけです（×1／×2／×4、一時停止、結果へスキップ）。
4. 結果画面では、残り耐久値と損耗率を表示します。同じ戦闘をリプレイで見直せます。

| 操作 | PC | スマホ |
| --- | --- | --- |
| 配置・選択 | 左クリック | タップ |
| 移動 | 置いたものを左ドラッグ | 置いたものをドラッグ |
| 連続配置 | — | 指でなぞる |
| カメラ回転 | 右ドラッグ（観戦中は左ドラッグ） | 2本指（観戦中は1本指） |
| 拡大縮小 | ホイール | ピンチ |
| 取り除く | Delete キー／「取り除く」ボタン | 「取り除く」ボタン |

## 開発コマンド

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run build` | 型チェックと本番ビルド（`dist/`） |
| `npm test` | テスト（決定論性、勝敗判定、配置の検証、マップ、CPU配置） |
| `npm run autobattle -- 20 hard` | バランス調整用の自動対戦。マップごとの勝率・平均時間・損耗率を表示 |
| `npm run trace -- river mongoose 3` | 1試合の経過をテキストで表示 |

数値を変えて試すときは、`BALANCE` で上書きできます。

```sh
BALANCE='{"fang":{"hp":180},"spitter":{"splash":1200}}' npm run autobattle -- 20 normal
```

## 構成

戦闘ロジックと描画を分けています。`src/sim` は Three.js にも DOM にも依存しないため、Node 上で大量の自動対戦を回せます。

```
src/
  sim/        戦闘ロジック（決定論的シミュレーション）
    config.ts      予算・拠点耐久値・制限時間などの基本パラメータ
    defs.ts        兵種・障害物の性能（仮の値）
    maps.ts        平野・山地・河辺の地形（点対称）
    placement.ts   配置データ・検証・シリアライズ（MatchSetup）
    world.ts       戦闘の状態
    battle.ts      1tickの処理、ユニットAI、勝敗判定
    pathfinding.ts A*（整数コスト）
  cpu/        CPU の配置AI（難易度＝予算の使い方の上手さ）
  render/     Three.js の描画（地形、ローポリモデル、エフェクト）
  ui/         画面（配置、観戦、結果）
scripts/      自動対戦・経過トレース
tests/        Vitest
```

### 決定論的シミュレーション

- 1秒20tickの固定タイムステップで計算します。
- 座標は「ミリタイル」（1タイル＝1000）の整数です。平方根も整数のニュートン法で求めます。`Math.sqrt` や三角関数は戦闘ロジックで使いません。
- 乱数はシードを共有する mulberry32 です。処理順はユニットの id 順で固定します。
- `MatchSetup`（マップ、シード、両軍の配置）があれば、同じ戦闘を再現できます。リプレイはこの仕組みで実装しています。オンライン対戦でも、このデータを交換するだけで成立します。

## 仕様書からの決定と仮の値

| 項目 | 値 | 備考 |
| --- | --- | --- |
| 予算 | 50 | 仕様どおり |
| 拠点の最大耐久値 | 1500 | 仮（仕様では未決） |
| 実戦の制限時間 | 120秒 | 仮（仕様では未決） |
| 準備の制限時間 | 90秒 | 仮。時間切れでその時点の配置で確定 |
| マップの大きさ | 18×30マス | 配置エリアは各陣営 16×7マス（全マップ共通） |
| 兵・障害物のコスト | 仕様書の仮コストどおり | 性能値は `src/sim/defs.ts` |

ルールの細部で、次のように決めました。

- 草むらと堀の上には兵を重ねて置けます。潜伏兵を草むらに隠すためです。柵と岩の上には置けません。
- 潜伏中のユニットが見えるのは、敵が1.5マス以内にいるとき、敵の偵察兵が5マス以内にいるとき、本人が攻撃した直後（3秒）です。偵察兵が見つけた敵は、味方全員から見えます。
- 自分の柵は味方も通れません。敵の柵は、迂回路がなければ壊して進みます。
- CPU戦では、敵の潜伏中のユニットは画面に表示されません。2人対戦とリプレイでは、両軍とも半透明で表示します。
